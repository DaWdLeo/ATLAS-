# ATLAS – Spatial Workspace

Browserbasierte, experimentelle 3D-Arbeitszentrale für das Touchboard.

Die erste Modulwelt ist eine interaktive Beispielbaustelle mit isometrischer Übersicht, Objekteditor und Begehungsmodus.

- Nur fiktive Beispieldaten verwenden.
- Keine fachlichen Freigaben, keine reale Gefahrstoffbewertung oder Ausbreitungssimulation.
- GitHub Pages hostet ausschließlich die öffentliche Demo, der Browser speichert lokale Änderungen.
- Three.js wird über ein externes CDN geladen.

## Aufruf

Nach Aktivierung von GitHub Pages: https://dawdleo.github.io/ATLAS-/

## Bedienung

Objekte auswählen, über den 3D-Gizmo verschieben, drehen und skalieren; aus der Bibliothek weitere Objekte hinzufügen. Die Szene lässt sich als JSON exportieren oder importieren. Zum Erkunden in den Modus *Begehung* wechseln. Ein heruntergeladenes GLB-Modell kann in der aktuellen Sitzung importiert werden.

## Hinweise

Demoinhalte dienen nur zur Visualisierung und sind keine georeferenzierten oder fachlich freigegebenen Daten. Für produktive Betriebsdaten ist eine private Backend-Anbindung nötig.
